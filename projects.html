Port scanner in Python

A command-line port scanner that recreates core Nmap features from scratch with raw sockets, to show how network reconnaissance works at a low level. It does not use Nmap.

  • TCP connect scan that classifies ports as open, closed or filtered
  • SYN scan using Scapy raw packets
  • Banner grabbing and service detection on open ports
  • OS guess from TTL and TCP window size
  • Parallel scanning across many ports, with a formatted report
python3 main.py -t 127.0.0.1 -p 1-1024

Intended for systems you own or have permission to test.

Python 3.10+, Scapy, sockets. Repository will be made public later.
